# OIBSIP-Spam-Detection
# Email Spam Detection using Machine Learning

This project aims to detect whether an email or message is spam or not using Machine Learning techniques in Python. Spam messages are unwanted or harmful messages that may contain advertisements, scams, phishing links, or malicious content.

In this project, a labeled dataset containing spam and ham (non-spam) messages is used to train a machine learning model. The text data is first cleaned and converted into numerical form using TF-IDF Vectorization. Then, the Multinomial Naive Bayes algorithm is used to classify messages as spam or ham.

The model is trained and tested on the dataset, and its performance is evaluated using accuracy score, classification report, and confusion matrix.

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Machine Learning Concepts Used

* Natural Language Processing (NLP)
* TF-IDF Vectorization
* Naive Bayes Classification

## Objective

To build a machine learning model capable of identifying spam messages accurately and automatically.

## Outcome

The trained model successfully predicts whether a message is spam or not with high accuracy.
